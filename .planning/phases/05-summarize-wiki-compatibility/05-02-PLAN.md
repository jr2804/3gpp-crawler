|----------|-------------|
| user CLI input -> summarize command | Untrusted option values enter command parsing and output rendering logic. |
| summarize output -> downstream wiki tooling | Rendered text may be consumed by automated wiki pipelines expecting stable structure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | T | summarize mode parsing | mitigate | Restrict mode input to explicit allowed values and fail fast on invalid input. |
| T-05-06 | R | wiki-ready output lineage | mitigate | Keep output as render transform over existing summarize result and preserve provenance-bearing text sections. |
| T-05-07 | D | CLI usability | mitigate | Keep standard mode default and preserve current output for existing scripts unless mode is explicitly changed. |
</threat_model>
