  <name>Task 2: Add workspace commands to main CLI (tdoc_app.py)</name>
  <files>src/tdoc_crawler/cli/tdoc_app.py</files>
  <action>
    Add a `workspace` Typer sub-app to the main CLI, with lazy imports from 3gpp-ai:

    ```python
    # Near the top with other imports
    from tdoc_crawler.cli.args import workspace_app as workspace_typer

    # In the app assembly section
    app.add_typer(workspace_typer, name="workspace", help="Manage extraction workspaces and export to external wiki apps")
    ```

    Create `src/tdoc_crawler/cli/args.py` (if it doesn't exist) or add to existing args module:

    ```python
    """CLI argument/option types for tdoc-crawler commands."""

    from __future__ import annotations

    from pathlib import Path
    from typing import Annotated

    import typer

    workspace_app = typer.Typer(
        help="Manage extraction workspaces and export to external wiki apps",
        no_args_is_help=True,
    )
    ```

    The actual command implementations in workspace_app should lazy-import from 3gpp-ai operations:

    ```python
    @workspace_app.command("init", help="Initialize a new extraction workspace")
    def workspace_init(
        name: Annotated[str, typer.Argument(help="Workspace name")],
    ) -> None:
        from threegpp_ai.operations.workspaces import create_workspace
        create_workspace(name)
        console.print(f"[green]Workspace '{name}' created.[/green]")

    @workspace_app.command("process", help="Extract structured data from workspace members")
    def workspace_process(
        name: Annotated[str, typer.Argument(help="Workspace name")],
        force: Annotated[bool, typer.Option("--force", help="Force re-extraction")] = False,
    ) -> None:
        from threegpp_ai.operations.workspaces import process_workspace
        process_workspace(name, force=force)
        console.print(f"[green]Workspace '{name}' processed.[/green]")

    @workspace_app.command("export", help="Export workspace to external wiki app format")
    def workspace_export(
        name: Annotated[str, typer.Argument(help="Workspace name")],
        target: Annotated[Path, typer.Option("--target", "-t", help="Output directory")],
        format: Annotated[str, typer.Option("--format", "-f", help="Target format: llm-wiki-compiler, llmwiki")] = "llm-wiki-compiler",
    ) -> None:
        from threegpp_ai.operations.workspace_export import export_workspace
        from threegpp_ai.operations.workspaces import get_workspace_path

        workspace_path = get_workspace_path(name)
        result = export_workspace(workspace_path, target, format=format)  # type: ignore[arg-type]
        console.print(f"[green]Exported {len(result.files_written)} files to {target}[/green]")
    ```

    Use Rich console for output (import from tdoc_crawler.cli.console or create a simple one).
  </action>
  <verify>grep -c "workspace" src/tdoc_crawler/cli/tdoc_app.py</verify>
  <done>Workspace commands exist in main CLI</done>

    ```python
        app()
    ```
