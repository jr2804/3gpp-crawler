## Key interfaces to preserve

From `packages/3gpp-ai/threegpp_ai/operations/workspaces/crud.py`:

- `create_workspace(workspace, auto_build, description)` → `WorkspaceRegistry`
- `delete_workspace(workspace, delete_artifacts)` → `bool`
- `list_workspaces()` → `list[WorkspaceRegistry]`
- `get_workspace(workspace)` → `WorkspaceRegistry | None`
- `set_active_workspace(workspace)` → `None`
- `ensure_default_workspace()` → `WorkspaceRegistry`

From `packages/3gpp-ai/threegpp_ai/operations/workspaces/members.py`:

- `list_workspace_members(workspace, include_inactive)` → `list[Member]`
- `add_workspace_members(workspace, items)` → `None`
- `remove_workspace_member(workspace, member)` → `None`

From `packages/3gpp-ai/threegpp_ai/models.py`:

- `Workspace` dataclass
- `DocumentClassification` pydantic model
- `SourceKind` enum
- `ExtractionQualityStatus` enum
- `ExtractionQualityReasonCode` enum

From `packages/3gpp-ai/threegpp_ai/operations/workspace_registry.py`:

- `WorkspaceRegistry` class (JSON persistence)

## Import mapping

| Old import | New import |
|---|---|
| `from threegpp_ai.operations.workspaces import create_workspace` | `from tdoc_crawler.workspaces import create_workspace` |
